# JMPlayer R2.7c — 사용자 매뉴얼

*[English manual here → MANUAL.en.md](MANUAL.en.md)*

JMPlayer는 표준 MIDI와 1990년대 한국 DOS 시절 음악/노래방 포맷을 사운드폰트 신디사이저와 소프트웨어 OPL3(애드립) FM 에뮬레이션으로 재생하는 Windows용 레트로 음악 플레이어입니다.

---

## 1. 지원 포맷

| 확장자 | 설명 | 사운드 엔진 | 가사 |
|---|---|---|---|
| `.mid` `.midi` | 표준 MIDI | 사운드폰트(JJoMe Synth) 또는 시스템 MIDI 장치 | – |
| `.nob` | 옥소리 노래방 (MIDI + 조합형 가사) | 사운드폰트 / MIDI 장치 | ✔ 음절 싱크 |
| `.oka` | 옥소리 노래방 (OPL) | OPL3 에뮬레이션 **또는 MIDI 음원**(14절) | ✔ 음절 싱크 |
| `.okm` `.okw` | 옥소리 노래방 (MIDI) | 사운드폰트 / MIDI 장치 | ✔ 음절 싱크 |

| `.ims` (+`.iss`) | IMS 애드립 음악 (+ISS 가사 파일) | OPL3 에뮬레이션 | ✔ (.iss 동반 시) |

## 2. 메인 창

### 상단 바
* **출력 장치 콤보** — `[JJoMe Synth (SoundFont)]`(내장 신디사이저), 시스템 MIDI 출력 장치, 또는 **Nuked SC-55**(아래 11절) 중 선택. MIDI/NOB/OKM 재생에 적용되며, OPL 포맷은 항상 내장 OPL3 에뮬레이터를 사용합니다.
* **R** — MIDI 장치 목록 새로고침.
* **⚙️** — **사운드폰트 관리자** 열기 (사용할 `.sf2` 교체).
* **검색창** — 플레이리스트 실시간 필터. 지우면 전체 목록 복귀.
* **F1** — 단축키/기능 도움말 창 열기.

### 플레이리스트
* 폴더 트리 방식: 폴더에서 **Enter** 또는 더블클릭으로 진입, `..`로 상위 이동.
* **File** / **Folder** — 개별 파일 추가 또는 폴더 전체 스캔(하위 폴더 포함).
* **Remove** — 선택 항목 제거, **Sort** — 정렬, **Playlist** — 플레이리스트 관리.
* **L** — 플레이리스트 새로고침.
* **Delete** 키 — 선택한 곡 영구 삭제.
* NOB/OKA/GYB 곡 제목은 파일 내 조합형/완성형 데이터에서 자동 디코딩됩니다.
* 마지막 재생 곡과 위치는 다음 실행 시 복원됩니다.

### 재생 컨트롤
* **REW / FW** — 5초 되감기 / 빨리감기 (← / → 키와 동일).
* **PREV / NEXT** — *현재 재생 중인 곡* 기준 이전/다음 곡 (목록 선택 위치는 건드리지 않음).
* **PLAY / STOP**, 진행 슬라이더(드래그 탐색), 볼륨 슬라이더.
* **반복 모드 버튼** — 1회 재생 → 한 곡 반복 → 전체 반복 → 셔플 순환.

### 시간/상태 표시
```
0008/0026 00:05 03:18  561 | Key: 0 | 132 - 100%
 곡번호/전체  현재  전체  틱   키변경    BPM   템포
```

### 우측 도구 버튼
| 버튼 | 기능 |
|---|---|
| 📊 | **채널 모니터** 창 토글 |
| **DSP** | OPL 출력 아날로그 시뮬레이션(LPF+새추레이션), 3단계: DSP → DSP2 → DSP3 → 끔 |
| 🎹 | **피아노 롤** 창 토글 |
| **BNK** | 애드립 포맷용 외부 OPL 악기 뱅크(`.BNK` / `.IBK`) 선택 |
| **MIDI** | `.gyb`/`.oka`를 OPL 대신 **MIDI 음원으로 연주** (아래 14절). 해당 포맷을 고르면 나타납니다 |
| **OUT** | **OPL 터널** — OPL 레지스터를 선택된 MIDI 장치로 내보냄 (아래 12절, `Ctrl+Shift+O`) |
| 📜 | **가사 창** 토글 |
| ⏺ | 오디오 출력을 WAV로 녹음 (**Ctrl+R**) |

## 4. 노래방 가사

* **가사 창**(📜)은 NOB / OKA / OKM / GYB(그리고 `.iss` 동반 IMS)의 디코딩된 가사를 표시합니다.
* 하이라이트는 노래를 따라 **음절 단위**로 진행되며, 한국어(조합형)와 영어(수출판 GYB) 가사를 모두 지원합니다. 줄이 바뀔 때는 다음 줄 첫 음절이 부드럽게 차오릅니다.
* **NOB 채널 선택** — 싱크 마커 채널이 특이한 곡은 가사 창에서 마커 채널을 직접 고를 수 있습니다.
* **가사 편집기** — 타이밍 기호를 지원하는 내장 편집기:
  * `~` 앞 음절을 한 박자 더 끌기
  * `#` 다음 음절 앞에 한 박자 쉼 삽입
  * `@` 이 줄 이후 처음부터 반복
* **편집 결과는 원본 파일을 건드리지 않습니다.** 곡과 같은 폴더에 **같은 이름의 `.txt`** 로 저장되고, 다음 재생부터 그 파일의 가사를 우선 사용합니다. `.NOB` 등 원본은 그대로 보존되므로, `.txt`를 지우면 원래 가사로 돌아갑니다.

## 5. 채널 모니터 (📊)

* **MIDI 모드** — 16채널을 OPL풍 다크 테마로 표시: 채널별 그라데이션 VU 바(피크 홀드), 악기명 카드, 프로그램 번호, 연주 중인 노트(셈여림별 색상). 파일이 담고 있는 리셋 메시지·제조사 SysEx·텍스트를 근거로 음원 방식(**GM / MT-32 / GS / XG**)을 판정해 근거와 함께 표시합니다. 파일이 아무것도 밝히지 않으면 회색으로 **`GM (assumed)`** 이라고 표시합니다 — GM으로 읽고 있다는 뜻이며, 파일이 실제로 GM이라고 선언한 경우와 구분됩니다.
* **OPL 모드** (IMS/ROL/SOP/GYB/OKA/VGM) — FM 20보이스를 악기 카드·음계·강도와 함께 동일한 VU 미터로 표시. 악기명은 실제 OPL 패치 변화를 실시간 반영합니다.

## 6. 피아노 롤 (🎹)

현재 연주 중인 음을 스크롤되는 노트 뷰로 표시합니다. MIDI와 OPL 재생 모두 지원.

## 7. OPL 사운드 옵션

* **DSP** — OPL 출력에 3단계 "아날로그 따뜻함"(로우패스 필터 + 소프트 새추레이션) 적용.
* **F12 스테레오 모드** — OPL 재생용 유사 스테레오 보이스 배치 9종 (모드 1 = 원본 모노).
* **BNK** — 외부 애드립 악기 뱅크(`.BNK`, `.IBK`) 로드. 자체 뱅크가 딸린 IMS/ROL 곡에 유용하며, 기본값으로 `STANDARD.BNK`가 동봉되어 있습니다.

## 8. 녹음 (⏺ / Ctrl+R)

재생 중인 소리를 포맷 무관하게 **WAV** 파일로 녹음합니다. 다시 누르면 정지. 녹음은 락-프리 버퍼로 동작해 재생에 영향을 주지 않습니다.

## 9. 사운드폰트 관리자 (⚙️)

내장 신디사이저가 사용할 `.sf2` 사운드폰트를 교체합니다. *GeneralUser GS*와 *VintageDreamsWaves* 두 개가 기본 동봉됩니다.

## 10. 설정·데이터 저장 위치

JMPlayer는 데이터를 **문서(Documents)** 폴더의 `JMPLAYER` 아래에 저장합니다:

| 파일 | 내용 |
|---|---|
| `문서\JMPLAYER\settings.ini` | 모든 설정 — 볼륨, 출력 장치, 반복 모드, DSP 단계, 마지막 재생 곡/위치, 창 옵션 |
| `문서\JMPLAYER\playlist.json` | 플레이리스트 트리 (추가한 폴더와 곡 목록) |

폴더는 저장할 내용이 처음 생길 때 만들어집니다. 플레이어를 완전 초기화하려면 이 두 파일을 삭제하고, 다른 PC로 설정을 옮기려면 이 두 파일을 복사하면 됩니다.

### 휴대용(포터블) 모드 — USB에 넣어 쓰기

실행 파일과 **같은 폴더에 `cfg` 라는 폴더를 직접 만들면**, 그때부터 설정과 플레이리스트를 문서 폴더가 아니라 그 안에 저장합니다. **문서 폴더에는 아무것도 만들지 않습니다.**

```
E:\JMPlayer\
    JMPlayer_R2.5h.exe
    cfg\        ← 직접 만드세요. 이 폴더가 있으면 휴대용 모드
    Music\      ← 자동 생성. 여기에 음악을 넣으세요
    BK\         ← 기본 제공 곡
```

* `cfg` 폴더는 프로그램이 만들지 않습니다. **사용자가 만드는 것이 곧 휴대용 모드를 켜는 신호**입니다.
* `cfg` 폴더를 지우면 다음 실행부터 다시 문서 폴더를 씁니다.
* 음악은 **`Music` 폴더에 넣으세요.** USB 드라이브 문자가 `E:`에서 `F:`로 바뀌어도 목록이 그대로 유지됩니다. 실행할 때마다 다시 훑으므로, 파일을 넣고 재실행하면 목록에 나타납니다.
* `Music` 폴더 밖에 두더라도 **같은 드라이브 안**이면 유지됩니다. 다른 드라이브에 있는 곡은 원래대로 전체 경로로 저장됩니다.
* 현재 어느 위치를 쓰고 있는지는 **`F1` 도움말 맨 아래**에서 확인할 수 있습니다.
* 참고: 프로그램이 남기는 파일은 모두 자기 폴더 안에 들어가지만, Windows 자체가 남기는 기록(최근 문서 목록 등)까지 막을 수는 없습니다.

## 11. Nuked SC-55 (선택 기능)

롤랜드 SC-55 음원을 사이클 단위로 재현하는 외부 에뮬레이터로 재생할 수 있습니다. 출력 장치 콤보에서 **Nuked SC-55**를 고르면 됩니다.

**동봉되지 않습니다.** 라이선스상 배포할 수 없어 직접 준비하셔야 합니다.

1. 프로그램 폴더의 `emulator-patch\` 안내에 따라 패치된 에뮬레이터를 빌드합니다.
2. 만들어진 실행 파일을 `NukedSC55\` 폴더에 넣습니다.
3. SC-55 롬 파일을 같은 폴더에 넣습니다. **롬은 롤랜드의 저작물이라 제공하지 않습니다.**

준비가 되면 곡을 시작할 때 에뮬레이터가 함께 뜨고, 부팅이 끝날 때까지 잠시 기다린 뒤 재생이 시작됩니다. loopMIDI 같은 가상 포트는 필요 없습니다.

## 12. OPL 터널 (**OUT**)

OPL 포맷을 재생하면서 칩 레지스터 값을 **선택된 MIDI 출력 장치로 그대로 내보냅니다.** 라즈베리파이 쥬크박스 등 실제/에뮬레이트된 OPL 하드웨어로 같은 연주를 울리기 위한 기능입니다.

받는 쪽 장치가 없으면 쓸 일이 없습니다. 켜고 끄기는 **OUT** 버튼 또는 `Ctrl+Shift+O`이며, 설정은 다음 실행까지 유지됩니다.

## 13. 음원 리셋 설정 (**F6**)

곡을 새로 재생할 때 출력 장치에 리셋 메시지를 먼저 보낼지 정합니다. 앞 곡의 음색·볼륨·이펙트가 다음 곡에 남는 것을 막아 줍니다.

* 보낼 리셋을 고를 수 있습니다 — **GM System On**, **GS Reset**(롤랜드), **XG System On**(야마하), **MT-32 Reset**.
* 리셋 뒤 **대기 시간(ms)** 을 줄 수 있습니다. 실제 하드웨어 음원은 리셋을 처리하는 데 시간이 걸려, 너무 빨리 연주를 시작하면 첫 음이 씹힙니다.
* **기본값은 꺼짐**입니다. 내장 사운드폰트만 쓴다면 필요 없고, 외부 MIDI 음원을 쓸 때 켜세요.

## 14. `.GYB` / `.OKA`를 MIDI 음원으로 (**MIDI** 버튼, **F5**)

가요방과 노래방45는 OPL 칩 대신 **MIDI 음원으로도 연주할 수 있었습니다**(음원 설정 7번). 이 기능은 그것을 되살린 것입니다.

**켜기** — 재생목록에서 `.gyb`나 `.oka`를 고르면 **MIDI** 버튼이 나타납니다. 누르면 그 곡은 OPL 대신 MIDI 음원(사운드폰트·시스템 MIDI 장치·Nuked SC-55)으로 연주됩니다. 재생 중이 아니어도 미리 켜둘 수 있습니다.

**왜 악기를 정해줘야 하나** — 이 포맷의 악기 번호는 GM 번호가 아니라 **곡이 가진 자체 OPL 악기표**를 가리킵니다. 그대로 MIDI로 보내면 베이스드럼이 비브라폰으로 나오는 식이 됩니다. 그래서 슬롯마다 GM 악기를 정해야 합니다.

**F5 — 악기 변경 창**

| 열 | 뜻 |
|---|---|
| OPL 악기 | 곡이 그 슬롯에 붙인 이름 |
| 음표 | 그 악기가 실제로 연주하는 음의 개수 (많은 것부터 정렬) |
| 기본값 출처 | 아래 세 가지 중 하나 |
| 종류 | 멜로디 / 타악기 |
| 바꿀 악기 | GM 악기 128개, 또는 타악기 노트 |

기본값은 신뢰도 순으로 정해집니다.

1. **곡에 저장된 배정** — 90년대에 누군가 도스 프로그램에서 직접 골라 파일에 남긴 값입니다. MT-32 음색 번호로 저장돼 있어 GM으로 옮겨 보여줍니다. 가장 믿을 만합니다.
2. **이름으로 추정** — 악기 이름을 규칙에 맞춰 찾습니다. 실제 라이브러리 기준 **약 89 %**가 여기서 해결됩니다.
3. **인식 못 함** — 아무것도 모르는 것. **귀로 골라야 할 것들이며, 대개 곡당 서너 개뿐입니다.** 「인식하지 못한 것만 보기」로 걸러 볼 수 있습니다.

**바꾸면 바로 들립니다.** 재생 중에 고르면 그 자리에서 소리가 바뀝니다(멜로디↔타악기 전환만은 채널이 달라져 곡을 다시 읽습니다). 바꾼 줄은 색이 달라지고, **모두 되돌리기**로 한 번에 원래대로 돌아갑니다.

**저장을 누르기 전에는 파일을 만들지 않습니다.** 이것저것 들어보다 닫으면 아무것도 남지 않습니다. **저장**을 누르면 곡 옆에 `노래이름.GYB.ini` 같은 작은 파일이 생기고, 다음에 그 곡을 열면 그대로 복원됩니다. 원본 곡 파일은 절대 고치지 않습니다.

> 쓰기가 막힌 위치(CD 등)에 있는 곡은 설정 폴더에 대신 저장됩니다.

## 15. 팁

* 모든 설정(볼륨, 장치, 반복 모드, DSP 단계, 마지막 폴더/위치)은 자동 저장됩니다.
* ZIP 압축파일을 바로 열 수 있습니다 — 내부 곡들이 목록에 표시되어 재생 가능합니다.
* OPL 곡 소리가 이상하면 우선 동봉된 `STANDARD.BNK`(BNK 버튼)와 DSP 끔 상태로 확인해 보세요.
